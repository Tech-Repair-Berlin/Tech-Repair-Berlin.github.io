## 📱 Sobre el Proyecto

Repositorio oficial del portal web de nuestro servicio técnico en Berlín. Diseñado con un enfoque moderno, cálido y minimalista para transmitir confianza y transparencia a nuestros clientes desde el primer segundo.

### 🔧 Servicios Principales
* **Especialistas en Móviles:** Diagnóstico avanzado, cambio de pantallas y baterías con componentes de máxima calidad.
* **Micro-soldadura:** Soluciones a nivel de placa base para fallos complejos que otros dan por perdidos.
* **Portátiles y PCs:** Optimización, ampliación de hardware, discos SSD y recuperación de sistemas.
